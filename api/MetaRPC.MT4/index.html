    static class Accounts ============================================================================ Accounts: the MT4 accounts (terminals) that belong to your API key. This is the call to make when you need the terminal ids of accounts that already exist - started from the dashboard or by an earlier ConnectEx - so that you can send them as the "id" header of every other call. Unlike the terminal calls it needs NO "id" header: it is answered from the platform's records of the API key sent in the "APIKey" header, and it never starts, wakes or bills a terminal. Accounts are listed newest first (by started_utc, then terminal_id) and returned by page. Only accounts of THIS platform's endpoint are listed (mt5.mrpc.pro lists MT5 accounts, mt4.mrpc.pro lists MT4 accounts). ============================================================================

    static class PublicAccount ============================================================================ PublicAccount: publish the MT4 account in the "id" header as a public master account for copy trading on mrpc.pro, change its public name and profit share, unpublish it, and read its public status. The call needs only the "APIKey" header (your mrpc_live_ key) and the "id" header (the terminal), like every other terminal call: no user key, no session, no admin key. The account must belong to the API key's user and be an MT4 account (mt4.mrpc.pro); any other id - another user's account, a deleted one, an MT5 one, an unknown one - is answered PUBLIC_ACCOUNT_TERMINAL_NOT_FOUND. The rules are the control panel's (mrpc.pro/my, "Public profile"): a public name of 2-32 letters, digits, spaces, "." "_" "-", and a profit share of 0-50 % (one decimal) charged to followers on winning copied trades. The terminal does not have to be running; the leaderboard lists the account once its first figures have been read from it (listed), which needs it connected. ============================================================================

    static class QuoteHistory ============================================================================ Quote history: the bars a chart is drawn from, for one symbol - returned by PAGE, oldest first. MetaTrader 4 keeps no tick history, so there is no Ticks call here; the MT5 API has one. Bars walks a time range forward. A page carries at most page_size bars and, when the range holds more, a next_page_token; passing that token back (same symbol, timeframe and range) returns the next page. An empty next_page_token means the range is exhausted. Tokens are opaque: a client stores and returns them, nothing else. History lives in the terminal and is fetched from the broker on demand. The first request for a symbol or a period the terminal has not loaded yet can take a few seconds, and when the broker has not delivered it within that time the call answers with an error whose error_code is QUOTE_HISTORY_NOT_READY - ask again a moment later. Every call needs the terminal id header ("id"), like every other call. ============================================================================
